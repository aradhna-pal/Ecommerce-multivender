Multi-Vendor E-Commerce Platform

A Comprehensive Solution for Buyers, Sellers, and Administrators

1. Project Overview

This project is a scalable, feature-rich Multi-Vendor E-commerce marketplace. Unlike a standard e-commerce website where a single owner sells products, this platform allows multiple independent vendors to register, upload, and sell their products. The Superadmin maintains complete control over vendors, commissions, and platform integrity.

Customer UI

Browse products, manage cart, and secure checkout.

Vendor Dashboard

Manage products, inventory, orders, and track earnings.

Superadmin Dashboard

Approve vendors, monitor platform analytics, and manage categories.

2. Technology Stack

HTML5 / CSS3 JavaScript / ES6 Bootstrap 5 .NET Core (C#) Backend RESTful APIs PostgreSQL Database
Frontend Tools
  • HTML/CSS/JS: Core structural and styling languages.
  • Bootstrap: For mobile-first responsive design.
  • Swiper.js / LightGallery: For product image carousels and zoom.
  • SweetAlert2: For interactive notifications.
Backend & Database Tools
  • .NET Web API: High-performance backend processing and routing.
  • Entity Framework Core: ORM for database interactions.
  • PostgreSQL: Robust, open-source relational database.
  • Postman: For testing API endpoints.
